# Iris 光影兼容 · 客户端 0.4.7

修复 [Issue #1](https://github.com/asidjwiaijd/cinema-r2/issues/1)：Iris 光影开启时，播放器有已解码帧，但世界中的电影屏幕不显示。

## 修改

原有自定义无光照屏幕管线没有接入 Iris 的光影绘制流程。启用光影时，屏幕现在使用 Minecraft 的 `RenderTypes.entityTranslucent` 路径，让 Iris 选择受支持的光影程序、扩展顶点格式、overlay/lightmap 纹理及对应绘制阶段。仅为自定义管线注册 Iris 程序仍不足以解决实测的丢画面，因此使用实际验证过的原版兼容路径。

libmpv 软件渲染的 `rgb0` 第四个字节是未定义填充，并非 alpha。现在在解码工作线程将它改为 255，再通过原有批量纹理上传送到游戏；RGB 不变。尽管兼容路径名称含 translucent，影片每个像素仍是不透明的，避免透出背景。没有使用会在部分光影包中进行加法混合的眼睛/发光实体路径。

通过反射调用 Iris 公开 API 的光影启用和阴影阶段查询，不新增 Iris 的必装依赖，也不引用 Iris 内部实现。关闭光影时恢复原有屏幕管线；屏幕不主动参与 Iris 阴影绘制。

## 更新

1. 正常退出 Minecraft。
2. 将客户端 `mods` 中旧的 `cinema-r2-*.jar` 替换为 `cinema-r2-0.4.7.jar`，同一实例仅保留一个版本。
3. 保留 Fabric API、libmpv 原生库和配置。此修复无需同时升级网站或 MC 服务端。

MC 版本仍为 26.1.2、Fabric Loader 0.19.5、Java 25。光影包的曝光、色调、雾与视距设置会影响屏幕观感；未承诺所有光影包输出与关闭光影时逐像素一致。

## 回归方式

在独立测试世界放置屏幕，播放黑、白、红、绿、蓝色条及带音轨视频；测试时开启云层，并在屏幕前放置不透明方块。分别验证：

- Iris 开启光影：色条可见，黑色区域不透出天空，背景云层不覆盖画面，前景方块仍能遮挡。
- 播放与暂停期间关闭/重新启用光影：屏幕持续可用，保持同一个播放器，不因切换重建解码器。
- 在控制器区块未加载时远距离观看：经服务器屏幕几何数据绘制。
- 不安装 Iris：原有深度测试、云层遮挡与彩色视频仍正常。

已验证的光影组合和测试结果见 [VALIDATION.md](../VALIDATION.md)。
