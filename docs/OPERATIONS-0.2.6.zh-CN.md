# 0.2.6 玩家与用量管理

在管理台打开「玩家管理」。在线、历史和封禁三个列表支持玩家名或 UUID 搜索。传送目的地是已在线屏幕附近的安全落点；找不到安全位置会返回错误。踢出/封禁支持原因；封禁写入 Minecraft 原生 banned-players.json，解封保留历史。网页等待 MC 执行回执，断线或指令过期不会显示成功。名单最多保留最近 2000 位，离线模式 UUID 不是正版身份验证。

「流量统计」显示 R2、EO、阿里云下载量，最近 30 秒上报均值，按 UTC 的日/月统计，最近 31 天和 168 小时趋势、玩家排行及每日 CSV。玩家必须使用 0.2.6 客户端；身份签名由 MC 认证桥下发，客户端不能直接声明任意 UUID。旧版未归属的下载量只计入线路总数。首次进入世界保留刚收到的身份，退出服务器清除身份。

累计计数以签名会话去重；包含 CDN 缓存命中的下载和失败响应字节，排除网页、未知客户端、未上报量及播放器已缓存内容的本地读取。统计随上报更新，不能代替云账单、访问日志或实现账单硬封顶。详细统计之前的 CDN 量保留为「未分类 CDN」，不能补推线路/玩家；R2 详细日/月/趋势从升级后开始。

在系统设置可设 CDN 日/月/单次播放预算，EO 与阿里云合并核算；0 是不限制。达到预算后关闭 CDN 媒体许可，点播健康 R2 继续；直播没有 R2 后备。客户端每十秒更新策略，策略有效十五秒；请求中的数据和云端已缓存公开内容仍可能继续消耗流量。

点播按 R2→EO→阿里云，直播按 EO→阿里云。R2/EO 单次媒体请求默认六秒，备用阿里云十五秒；错误响应、连接失败或无效清单会切源。失败 R2/EO 冷却三十秒，再在下一次媒体请求中尝试恢复。保持一个 libmpv 解码器和缓存，不能保证缓存不足时无卡顿。目前没有按吞吐率切源，也没有读取 EO 账户额度。两家 CDN 同一个源站，不提供源站容灾。

OBS 服务器为 rtmp://192.168.8.244:1935/live，原密钥保留，从管理台直播中心获取。Linux 后台自动接收，FFmpeg 转码后的 HLS 直接经公网加速域名分发；Windows 只需运行 MC。公网推流需要独立 TCP 映射至 192.168.8.244:1935，网站 HTTPS CDN 地址不能直接作为 RTMP 入口。
