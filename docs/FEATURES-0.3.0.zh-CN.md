# 0.3.0 影院管理员、音频图片与林地影院

管理台、Minecraft 客户端和服务端均已安装 0.3.0。网站继续运行在 192.168.8.244 的独立 32GB 盘，MC 仍在 Windows 本机。管理入口：https://live.mc.acgzjd.cn，备用：https://live.al.mc.acgzjd.cn。

## 在网页授权影院管理员

玩家先进入游戏，再打开网页「玩家管理 → 在线」，在对应行点击「设为管理员」并确认。授权收到 MC 成功回执后生效。管理员可以建造和移除普通方块，包括调整影院；这不授予 OP、服务器命令、网页登录或资源管理权限。网页管理密码保持原有设置。

管理员名单按 UUID 保存到 MC 的 `config/cinemar2-admins.json`，可在网页撤销，包括撤销离线玩家。由于服务器按要求关闭正版验证，名字及离线 UUID 不能证明身份：**每次重新连接或服务器重启后，建造授权失效；玩家在线时需在网页点击「授权本次连接」**。授权指令绑定连接编号、有效期 30 秒，旧连接指令不能授权新连接。测试账号的授权已清除，没有自动将真实玩家设为管理员。

普通观众也使用创造模式，可飞行和观看，但不能从创造物品栏取得物品、破坏、放置、使用方块或干扰实体。管理员仍受爆炸、危险物品、掉落物、PVP 和活动范围限制；改造地形应使用普通建筑方块。

## 上传音频与图片

资源库 → 上传资源，选择以下文件，等待处理完成，再在播控台选择素材并「立即播放到 N 块屏幕」。独立预览不改变屏幕节目，默认静音。

| 类型 | 支持格式 | 游戏呈现 |
| --- | --- | --- |
| 音频 | MP3、WAV、FLAC、OGG、M4A、AAC | 静态音乐画面及音频；时长取自原音频 |
| 静态图片 | PNG、JPG/JPEG、WebP | 保持比例、补边显示，无声音 |
| 视频 | MP4、MKV、MOV、WebM | 原有视频播放 |

图片展示时长默认 15 秒，可设置 1–3600 秒。屏幕「结束保持」会留下最后一帧；「单片循环」持续展示；将多张图片加入队列并应用「顺序轮播」可做幻灯片。音频也支持暂停、定位、循环和队列轮播。原版 Minecraft 的声音设备设置、系统音量仍影响实际听感。

音频和图片由服务器 FFmpeg 先生成 720p/1080p H.264/AAC 或无声视频，再进入原有 MP4/HLS 处理、源站与 R2 同步链路。无需客户端分别实现图片及音频解码。图片限制单边不超过 8192、总像素不超过 4000 万，音频时长最多 24 小时；实际可用量仍受磁盘及 R2 预算限制。单次文件上传上限仍为 4 GiB。转码产物也占空间，归档不会释放空间。

首版支持文件上传；「导入媒体链接」继续要求可播放的 MP4/HLS，不能直接导入原始 JPG/MP3 地址。图片为静态展示，未新增 GIF/SVG 或动画图片播放。资源库保留「音频验证 · 音乐卡片」「图片验证 · 色条」两个 4 秒示例，可自行预览或发送到屏幕。

## 场景与保护

主屏控制器保持主世界 `(0,100,-8)`、朝南、18 格宽。场地为林地露天阶梯影院，5 排各 10 个木阶座位，中央通道，两侧树林、花草、灯柱与小池塘。后部入口/出生点 `(0,104,36)`，面向屏幕。座位采用原版阶梯造型，没有额外的坐下动作模组。

时间固定为 12000（傍晚），天气固定晴朗。服务端关闭昼夜/天气变化、火蔓延、自然刷怪、怪物破坏与 PVP；拦截 TNT、爆炸伤害与地形破坏、掉落物、投射物、船、矿车、末影水晶等干扰实体，禁止危险物品和自定义创造物品组件。玩家离开约定活动范围或进入其他维度，会返回影院。主屏所在 `(0,-1)` 区块保持加载，无人时网页仍能控制主屏；「无人暂停」策略仍按屏幕设置执行。

**这是专用影院服务器：`protectCinema=true` 的建造/实体/爆炸保护作用于整个服务端世界，不只是座位附近。** 不是通用生存服务器的领地插件，也不能保证阻挡所有客户端恶意行为、网络攻击或管理员滥用。关闭保护会关闭这些服务端限制；已经保存的游戏规则、世界边界、创造模式和强制加载标记需另外恢复。

网页「玩家管理」显示保护、搭建进度与就绪状态。「重建场景」会替换主影院周围有限区域内的地形和装饰，保留原屏幕控制器、当前节目及策略；管理员自建装饰也可能被覆盖。初次改造前的完整世界备份在 `E:\mc\cinema-r2\.tools\backup-before-0.3.0\world`。恢复时先停止 MC，再替换世界；不要在运行中的世界上直接覆盖文件。

## 验收范围

Node 16 项测试通过，包括真实 FFmpeg 音频/图片处理、非法音频拒绝和管理员连接绑定；场景规划 2 项测试通过，React 与 Fabric 发布构建通过。实际已安装 Minecraft 客户端验证音频出帧并建立 WASAPI 声音设备、图片出帧且无声音，两种测试资源源站/R2 副本就绪；探针对照具体资源 URL，避免把旧节目的帧误算为新素材。

实际世界确认 50 个座位、创造模式、晴朗傍晚、PVP 关闭、普通玩家不能破坏、管理员可以破坏、重连后权限失效、爆炸和 TNT 被拦截。网页上传表单及两种独立预览通过。未进行 50 人同时在线负载测试；50 指已搭建的座位数量。原有 6 路 R2、600 秒 TS、40/20 秒兜底与服务器 RTMP 保持。
